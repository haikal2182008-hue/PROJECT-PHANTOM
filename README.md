# PROJECT PHANTOM
Android open-world prototype.

## Build APK
1. Open GitHub Actions.
2. Select Build PROJECT PHANTOM APK.
3. Press Run workflow.
4. When complete, download the PROJECT-PHANTOM-APK artifact.
5. Extract the ZIP and install app-debug.apk on Android.

This is an early playable prototype, not a GTA-scale production game. Three.js is loaded from a CDN, so an internet connection is required at launch.
